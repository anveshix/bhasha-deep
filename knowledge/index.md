# Santali Linguistic Knowledge Base & Technical Report

## 1. Linguistic Taxonomy & Etymology
- **Family**: Austroasiatic language family, Munda branch.
- **Skrefsrud Taxonomy**: "Turanian family" / "Compounding languages", comparable to Turkish in grammatical logic and structural consistency.
- **Related Languages/Dialects**: Kolhe, Koda, Mahle, Birhor, Munda, Ho, Korku. Santali is the most systematically developed among Munda languages.
- **'Hor' and 'Hasd-ak'**: 'Hor' means human being. First human progenitor: 'Pilchu Had-am'. The root 'Had' is common across tribal groups. Ancient Genitive sign '-ak' (e.g. 'Hasd-ak' = "belonging to Hasd").

## 2. Phonology and Feature Logic
- **Vowels**: 10 long, 10 short vowels, plus Nasal (añ, eñ, iñ, oñ, uñ) and Neutral gutturals (ạ, ị, ọ, ụ).
- **Inspirates/Jerks (k', ch', t', p')**: Produced by drawing breath inwards and abruptly closing vocal chords. Never occur word-initially.
- **Softening Shift**: Softens before vowels ($k' \to g, ch' \to j, t' \to d, p' \to b$). Inhibited when followed by vowel 'a' (e.g., *chahapan* retains 'p').

## 3. Noun Architecture & Genitive Rigidity
- **Animate Possession**: Uses `ren` suffix (e.g. *Kora-ren enga* - 'लड़के की माँ').
- **Inanimate Possession**: Uses `reak'`, `an`, `rean`, `ak'` suffixes (e.g. *Tanga-reak' dạt'o* - 'कुल्हाड़ी की धार').
- **Master Case Table**:
  - Nominative: Root
  - Genitive: `ren` (Animate), `reak'` / `an` (Inanimate)
  - Instrumental: `te`, `hotete`
  - Dative: `then`, `thech` (Animate), `te` (Inanimate)
  - Accusative: Root / Object Infix
  - Ablative: `khon`, `khoch`
  - Locative: `re`, `talare`

## 4. Pronoun & Social Pragmatics
- **Exclusive We**: *Alin* (dual), *Ale* (plural) - listener excluded.
- **Inclusive We**: *Alan* (dual), *Abo* (plural) - listener included.
- **Social Honorific Rules**:
  - In-laws (Sukur / Dama / Bahu) address each other in Dual (*Aben* / *Alin*).
  - Samdhis address each other in Plural (*Ape* / *Ale*).
  - Husband and wife are treated as a unified pair.

## 5. Verb Logic & The 23 Tenses Matrix
Structure: `[Root] + [Tense Sign] + [Object Infix] + [a] + [Subject Suffix]`
- **5 Voices**: Active, Reciprocal Active (*Dapal*), Reflexive/Passive (*Dal-ok'*), Reciprocal Reflexive, Deponents.
- **23 Tense Signs**:
  1. Future: Root
  2. Gen. Inc. Pres: `-et'`
  3. Spec. Inc. Pres: `-et'kan`
  4. Recent Past: `-ket'`
  5. Anterior Past: `-len`
  6. Perfect: `-akat'`
  7. Gen. Inc. Past: `-et'tahekan`
  8. Spec. Inc. Past: `-et'kantahekan`
  9. Indecisive Pluperfect: `-letahekan`
  10. Decisive Pluperfect: `-akat'tahekan`
  11. Inchoative Fut: `-ok'-a`
  12. Inchoative Pres: `-ok'-kana`
  13. Inchoative Past: `-ok'-kantahekan`
  14. Optative: `-ke`
  15. Conditional: `-ko`
  16. Contingent: `-le`
  17. Prelim Fut: `-le-en-re`
  18. Prelim Expost: `-le-re-ho`
  19. Prelim Persuasive: `-le-re-nahak'`
  20. Prelim Admissive: `-le-re-ba-e`
  21. Continuative Fut: `-aka-tahen-a`
  22. Continuative Pres: `-aka-tahen-kana`
  23. Continuative Past: `-aka-tahen-kantahekan`

## 7. AI Model Training Constraints
1. **Infix Parsing Logic**: Parse `Root + Tense + Object Infix + a + Subject`.
2. **Reduplication**: Recognize jingling/reduplicated forms (`da-dal`, `ne-nel`) as intensive aspect.
3. **Anatomical TTS**: Simulate inspirates / jerks (`k'`, `ch'`, `t'`, `p'`) with inward airflow + glottal closure.
4. **Social Honorific Awareness**: Automatically rank Dual/Plural pronouns higher when discussing in-laws or elder relatives.
5. **Locative Base Logic**: Use spatial/locative origin as the foundation for case marker mappings.
